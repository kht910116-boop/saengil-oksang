# 오늘의 주인공 (saengil-oksang)

친구 생일에 다 같이 불을 켜는 3D 파티 서비스.
친구들이 파티장에 등불을 모으는 동안 주인공은 닫힌 문 앞에서 기다리고, 정한 시각(자정 또는 생일 당일 저녁 등)이 되면 문이 열리며 모든 접속자 화면에서 동시에 점등됩니다.

## 기능
- 첫 화면 '파티장 고르기': 게임 서버를 고르듯 지금 열린 파티장 목록에서 골라 들어감(지금 파티 중 먼저, 그다음 점등이 가까운 순 · 접속 인원 원활/북적/가득 · 등불·응원단 수). 목록 공개는 만들 때 고르고 관리 화면에서 끄고 켤 수 있음. 시험용 파티장은 목록에 안 나옴
- 파티장 만들기: 두 가지
  - 친구 생일 · 깜짝 파티: 주인공 이름·생일·점등 시각·파티 장소 → 친구 링크 / 주인공 링크 / 관리 링크 3개(주인공은 점등 15초 전까지 문 앞 대기)
  - 내 생일 · 직접 열기: 생일자가 바로 들어가 친구를 맞이하고, 관리(응원단·목록 공개·등불 숨김·삭제)도 직접 함 → 초대 링크 / 내 입장 링크
- 가상 응원단: 파티장을 연 사람이 관리 화면에서 3·5·10명씩 최대 20명 보냄. 이름 앞에 '응원단'이 붙어 진짜 친구와 구분되고, 모두의 화면에서 돌아다니며 점등식·단체 사진에도 함께함. 한 명마다 등불 하나를 달아 유성우 목표(등불 20개)를 채움
- 파티 장소 5곳(고르면 배경이 바로 바뀜): 밤바다 크루즈 · 오로라 유리돔 · 구름 위 열기구 광장 · 우주 전망 라운지 · 도시 옥상 (`src/venues/`)
- 넓은 장소와 놀거리(가까이 가면 버튼, 함께 보는 것은 모두의 화면에서 같이 일어남)
  - 밤바다 크루즈(뱃머리까지 긴 배): 뱃고동 울리기 · 조타륜 돌리기(배가 방향을 틈) · 망원경으로 등대 보기 · 수영장
  - 오로라 유리돔(지름 2배): 스케이트장(미끄러짐) · 눈사람 함께 만들기 · 벽난로 장작 넣기 · 오로라 수정(색 바꾸기)
  - 구름 위 열기구 광장: 열기구 타고 하늘로(약 16초) · 구름 트램펄린 · 소원의 종
  - 우주 전망 라운지: 무중력 구역(둥둥) · 순간이동 패드 2개 · 지구 망원경
  - 도시 옥상: 미러볼 댄스 플로어 · 네온 포토존(사진 찍기) · 달 망원경
- 파티 차림(모든 장소): 3단 케이크(크림·딸기·마카롱·금빛 토퍼)와 식탁보 두른 테이블·접시·컵, 뷔페(컵케이크 탑·마카롱 탑·피자·치킨·도넛·과일·펀치), 선물 더미, 깃발 줄, '생일 축하해' 현수막, 입구 풍선 아치, 바닥 색종이. 뷔페에서 '간식 먹기'·'건배하기'. 촛불을 불 때 주인공은 작은 단상에 올라선다
- 캐릭터: 반짝이는 눈·깜빡임·표정(웃는 눈 ^^, 놀란 O 입, 잠든 눈, 냠냠), 가끔 두리번, 꾸미기 소품(리본·고양이 귀·토끼 귀·안경·꽃 핀)
- 장소별 테마 파티: 크루즈(선상 디너·신호 깃발·밧줄 아치·닻 케이크) · 오로라(핫초코 바·진저브레드·얼음 백조·눈송이·불빛 트리) · 열기구(가든 티파티·꽃 가랜드·바람개비·피크닉 담요·나비 케이크) · 우주(네온 바·빛나는 시험관·홀로 링·로켓·은하 케이크) · 옥상(바비큐 그릴·쿨러·카페 전구·드립 케이크). 손에 드는 간식·음료 소품도 장소마다 다름
- 앉기: 벤치·소파·우주 의자·피크닉 담요에 '앉기'(자리 높이·방향 맞춤, 모두에게 같은 모습)
- 겹침 방지: 인형끼리 가까우면 서로 비켜섬
- 같이 하는 동작: 근처 친구와 하이파이브·포옹·손잡고 빙글빙글·기차놀이·단체 셀카(서버가 시작 시각을 맞춰 모두의 화면에서 같은 안무)
- 배경 음악: 첫 화면(Make a Wish) · 기다릴 때 · 문 앞 · 점등 · 점등 뒤 파티(Birthday Chimes) · 주인공 입장(Royal Entrance)
- 캐릭터 동작 17가지('동작' 버튼): 점프·앉기·손 흔들기·춤추기·꾸벅 인사·공중제비·빙글빙글·만세·엉덩이춤·깜짝·감동·기지개·벌러덩·졸기·하트·냠냠·건배. 앉기·눕기·졸기·춤은 걸을 때까지 유지
- 파티 의상: 입장할 때 드레스·정장·파티복 중 고르기, 주인공은 왕관과 망토(장소·의상은 목록 구조라 유료 항목을 나중에 추가 가능)
- 주인공 입장 행진: 주인공이 들어오면 친구들이 양옆으로 줄을 서고, 조명을 받으며 입구에서 케이크까지 걸어 들어옴
- 의식(점등식·촛불 끄기): 5초 카운트다운과 함께 모두가 정해진 대열에 서고(주인공은 케이크 옆, 친구들은 뒤 반원), 걷기·등불·선물은 잠기고 하트·별·박수만 크게. 끝나면 자유롭게
- 주인공 연출: 금빛 반짝이가 늘 주위를 돌고, 입장 때 손 흔들기, 점등 순간 한 바퀴 돌고 만세
- 촛불 끄기: 케이크 쪽으로 몸을 돌려 숨을 들이쉬고(볼이 부풂) 몸을 숙여 '후~' → 입김이 날아가 촛불이 눕다가 하나씩 꺼지고 연기가 오름 → 꽃가루·박수·파티 나팔
- 몸짓: 리액션을 누르면 내 인형이 박수·하트·만세 몸짓, 노래할 때 다 같이 좌우로 흔들기
- 소리: 장소별 배경 소리(파도·눈바람과 장작·높은 바람과 열기구 버너·우주선 웅웅·도시), 등불 '슈욱+종소리', 선물 종류별 소리, 친구 입장 '딩동', 문 열림, 입장 팡파르, 점등 카운트다운, 사진 찰칵, 촛불 '후~', 박수, 닫힘 오르골
- 생일 노래 떼창: 주인공이 촛불을 끄면 모두의 화면에서 같은 박자로 노래(가사에 주인공 이름)를 부른 뒤 촛불이 꺼짐
- 단체 사진: 주인공(또는 만든 사람)이 누르면 3-2-1 뒤 모두가 케이크 뒤에 모여 같은 순간을 찍음
- 기억 카드: 모든 등불 문구를 한 장의 이미지로 저장(파티장이 닫히기 전에)
- 준비 현황판(만든 사람): 등불·보낸 친구·선물·접속 수, 주인공 링크 열람 여부, 지금 하면 좋은 일
- 점등 알림: 웹 푸시로 30분·5분 전 알림(아이폰은 홈 화면 추가 후), 캘린더 파일도 제공
- 가볍게 보기: 3D 없이 등불 목록과 점등 소식만(오래된 휴대폰용, 버벅이면 먼저 권함)
- 실시간 동시 접속: 아바타 이동, 접속자 수, 등불이 바로 공유됨(방당 40명)
- 등불: 준비된 축하 문구 16개 중에서 고름(자유 입력 없음), 파티장당 180개
- 이름 필터(서버·화면 공통, `src/config.js`의 validateName): 한글 완성형·영어만 허용, 숫자·기호·자음만 쓴 글자·이모지 차단, 욕설 변형·영타 욕설, 연락처·계정·주소 단어, 한글로 쓴 숫자 4자 이상, 운영자 사칭 차단
- 주인공: 자정 15초 전까지 닫힌 문만 보임(등불 개수만), 자정 뒤 처음 들어오면 점등 연출을 한 번 보여줌
- 관리: 만든 사람은 링크 다시 보기, 등불 숨기기/다시 보이기, 파티장 지우기. 주인공은 문이 열린 뒤 등불 숨기기 가능
- 신고: 같은 사람은 1번만 집계, 3건이면 자동 숨김. 운영자 화면 `/admin?key=…`
- 파티장 선물: 자정 불꽃놀이·풍선 묶음·케이크 토핑(익명 가능, 익명이면 이름을 저장하지 않음). 지금은 전부 무료(PAYMENT_MODE=free, 한 사람당 10분에 10개)
- 카카오톡·SNS 링크 미리보기(파티장마다 제목·설명, 장소별 이미지 `public/og/`), 점등 영상 저장(지원 브라우저)
- 느린 기기에서 해상도·빛 번짐 자동 조절, 숨겨진 화면에서는 렌더링 중지
- 개인정보처리방침 `/privacy`, 이용약관 `/terms`
- 하루짜리 파티장: 생일 다음 날 0시 5분에 닫히고 데이터 삭제, 하루 새 파티장 300개 상한, 생일 60일 전부터 생성
- 운영: 측정·통계(`/admin/stats`), 화면 오류 기록, 매일 백업(`/admin/backup`), 구경 모드(방당 아바타 40명 초과 시)

## 시험
```bash
npm run build
npm test            # 단위·API·실시간 시험
npm run test:e2e    # 브라우저 통합 시험(Playwright 필요)
npm run test:load   # 부하 시험(결과는 DEPLOY.md)
```

## 로컬 실행
```bash
npm install
npm run build              # 화면 빌드(dist/)
ADMIN_KEY=비밀키 npm start  # http://localhost:8787
```
- 샘플 파티장: `/r/demo`
- 시험용 파티장: 첫 화면에서 "시험해 보기: 1분 뒤에 바로 점등" 체크
- 샘플에서 장소 바로 보기: `/r/demo?venue=aurora` (cruise · aurora · sky · space · rooftop), 가볍게 보기: `?lite=1`

## 환경 변수
| 이름 | 설명 | 기본값 |
|---|---|---|
| `PORT` | 서버 포트 | 8787 |
| `DB_PATH` | SQLite 파일 위치(배포 시 영구 디스크에) | `data/rooftop.db` |
| `ADMIN_KEY` | 운영자 화면 키. 비우면 운영자 화면이 꺼짐 | 없음 |
| `IP_SALT` | 신고 중복 판정용 IP 해시 소금값. 고정해 두기 | 실행할 때마다 무작위 |
| `NODE_ENV` | `production`이면 index.html을 캐시 | |
| `VAPID_PUBLIC_KEY` · `VAPID_PRIVATE_KEY` | 점등 알림(웹 푸시) 서버 열쇠. 비우면 처음 실행 때 `data/vapid.json`에 만들어 계속 씀(데이터 폴더가 영구 디스크면 따로 넣지 않아도 됨) | 자동 생성 |
| `TRUST_PROXY` | `1`이면 프록시가 넘긴 접속 IP(x-forwarded-for)를 믿음. Cloudflare 등 뒤에 둘 때만 켜기 | 꺼짐 |

## 배포
쉬운 순서는 `DEPLOY.md`(Railway). 아래는 직접 서버에 올릴 때의 참고입니다.

- Docker: `docker build -t saengil-oksang . && docker run -p 8787:8787 -v $(pwd)/data:/app/data -e ADMIN_KEY=… -e IP_SALT=… saengil-oksang`
- 반드시 HTTPS 뒤에 두세요(WebSocket이 `wss://`로 연결됨). 프록시는 WebSocket 업그레이드를 통과시켜야 합니다.
- 정적 파일(`/assets/`, 이미지, 음악)은 Cloudflare 같은 CDN 캐시를 붙이면 전송비가 크게 줄어듭니다.
- 백업: `data/rooftop.db` 파일 하나만 복사하면 됩니다.
- 개인정보처리방침에는 Railway(싱가포르 지역) 기준으로 국외 이전이 적혀 있습니다. 다른 곳에 올리면 `public/privacy.html` 4항을 바꿔야 합니다.
- 상태 확인 주소: `/healthz`

## BGM
`public/audio/`에 상황별 곡 3개(bgm-rooftop / bgm-door / bgm-midnight)가 들어 있습니다. 소리를 켠 사람만 내려받습니다. 곡 출처와 손질 내용, 새 곡 만드는 법은 `BGM_GUIDE.md`.

## 구조
- `server/index.js` — HTTP·WebSocket 서버, SQLite 저장, 미리보기·운영자 화면
- `src/config.js` — 서버와 화면이 같이 쓰는 설정(문구, 한도, 보관 기간)
- `src/main.js` — 화면(모드: 첫 화면 / 샘플 / 실제 파티장)
- `src/world.js` · `src/venues/` — 파티 장소 5곳(모두 코드로 그림, 3D 모델 파일 없음). 새 장소는 `common.js`의 부품으로 만들고 `config.js`의 VENUES에 추가
- `src/avatar.js` — 마시멜로 인형과 파티 의상(OUTFIT_BUILDERS)
- `src/song.js` · `src/memory.js` · `src/photo.js` — 생일 노래 박자·가사, 기억 카드, 기념사진
- `server/push.js` · `public/sw.js` — 점등 알림(웹 푸시)
- `src/audio.js` · `src/recorder.js` · `src/net.js` — 소리, 영상·캘린더, 통신
- `public/` — 개인정보처리방침, 이용약관, 미리보기 이미지, BGM
